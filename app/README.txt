刊禾 · Biomed Reader 2.1
======================

安装与启动
----------
适用于 Windows 10/11，64 位系统。
安装版：运行 BiomedReader_Setup_2.1_x64.exe，按提示完成安装。
目录版：完整解压 BiomedReader_2.1_Portable_x64.zip，运行其中的 BiomedReader.exe。
已内置 Python 3.12、依赖库和内嵌浏览器组件，无需另外安装 Python。
请保留目录中的 _internal 文件夹，不能单独复制 EXE 运行。
本次仅更新 Windows 2.1；macOS 请以独立仓库实际发布的版本为准。

升级与数据安全
--------------
升级前退出软件，并在设置中备份本地数据为 ZIP。
安装标识和历史数据目录保持兼容，方案、缓存、收藏、目录及 PDF 链接继续使用。
默认数据位置：%LOCALAPPDATA%\OrangeReader\BiomedLiterature。
已移动或链接数据目录的用户继续使用已配置路径。
PDF 副本保存在当前本地数据目录的 paper 子文件夹。
卸载默认保留个人数据。软件没有数字签名，系统可能显示发布者提示。

2.1 版本说明
------------
应用版本、设置左下角版本、联网客户端标识、安装包和程序文件信息统一为 2.1。
保留当前全部功能，包括来源独立的日级增量检查点与大缓存恢复策略。
Windows 文件属性中的产品版本显示为 2.1，数字版本资源使用 2.1.0.0。

关键词方案
----------
主页点击“添加关键词组”，设置名称与关键词或布尔表达式，例如：
R-loop OR "DNA-RNA hybrid"
在编辑方案中选择 PubMed、预印本官网或两者，并分别设置候选数。
新方案两个候选数默认 0，表示不限，默认按最新发表排序。
同时启用 bioRxiv 与 medRxiv 时，每个站点各使用同一预印本候选数。
文章类型可多选，仅筛选 PubMed。年份上下限可输入或下拉选择。
多个期刊目录按并集合并，期刊目录与最低 JIF 仅筛选 PubMed。
关键词卡片默认每行五张，可以拖动排序与调整宽度。

联网检索与增量刷新
------------------
PubMed 使用 NCBI E-utilities，预印本使用 bioRxiv/medRxiv 对应官网关键词搜索。
在设置中选择预印本站点和最近年限，默认最近两年。
PubMed 搜索范围：默认或标题与摘要。
预印本搜索范围：默认、标题与摘要、全文、全文与标题摘要。
官网验证需本人手动完成。窗口可最小化，关闭窗口将取消官网检索。
限流时等待网站恢复，频繁重新加载可能延长等待。
首次检索完整建立基线，条件不变时后续按各来源上次成功刷新日到本地今天检索。
日期包含两个边界，按 DOI/PMID 去重合并。增量不因候选数截断。
PubMed 按发表日期，预印本按版本发布日期。晚收录旧文可通过完整检索核查。
各来源分别保存完成状态，一个来源失败不要求成功来源重复完整检索。
缺少成功检查点的旧缓存需要一次核验，PubMed 复用已有摘要并补取缺失记录。
检索分批保存新结果，取消或部分失败后保留本次已缓存的新文章。
整体成功刷新时间仅在检索完成后更新，其它关键词卡片的时间保持独立。
需要重新核查全部范围时，勾选“完整检索”。

排序与阅读
----------
最新发表：优先显示日期较新的文章。
最相关：使用来源排名与已缓存内容的相关性信息。
综合最佳：相关性权重 0.72，时效性权重 0.28，时间衰减半衰期 180 天。
综合最佳的预印本候选先按官网 Newest first 获取，再本地排序。
候选集、筛选条件、晚收录文章和来源差异会影响与官网结果的对应关系。
表格按需加载后续行，列宽可拖动调整。卡片每页 24 篇，可选择宽松或紧密密度。
关键词卡片模式记录页面与阅读位置。预印本标题显示为浅红加粗。
预印本缺失摘要按当前页面在后台补取，已获取的摘要可以离线阅读。
“检索源”只筛选当前缓存的 PubMed/bioRxiv/medRxiv 文章，不删除缓存。
可隐藏或取消隐藏文章，隐藏设置只作用于当前关键词方案。
点击 DOI/文章界面在默认浏览器打开，详情文字保留，并标记本轮已访问文章。
联网刷新重置 DOI 访问状态，保留收藏、隐藏标记、笔记及 PDF 链接。

收藏、PDF 与分享
----------------
在关键词方案中收藏的文章归入同名分组，删除方案后收藏分组保留。
支持自定义分组、分组排序、文章复制或移动到多个目标分组。
收藏分组默认每行五张，可拖动排序，可用表格或嵌入式卡片浏览文章。
收藏文章详情中点击“链接文章”，选择已下载的 PDF。
软件复制 PDF 到当前数据目录的 paper 文件夹，并用文章标题命名。
链接成功且文件存在时，“查看原文”通过默认 PDF 阅读器打开副本。
所有“取消收藏”入口（包括关键词方案、文章详情和批量取消）都会先弹出确认窗口。
确认后从全部收藏分组移除所选文章，并解除 PDF 链接、删除软件管理且没有其它文章引用的 PDF 副本。
paper 目录之外的源 PDF、文章检索缓存和笔记保留；选择“保留收藏”或关闭确认窗不执行删除。
若文件占用导致删除失败，软件提示并保留收藏关联，关闭阅读器后可重试。
打包分享时先选分组，再选择右侧文章，最终仅导出已勾选文章，可包含链接的 PDF。
读取分享 ZIP 会导入文章、分组、笔记及包内 PDF，并恢复关联。

期刊目录与 JIF
--------------
内置 IF 6-10、IF 10-20、IF 20-500、NC精选与 NC扩选五个目录。
IF 三组按 2025 年 JIF 固定划分：6≤JIF<10，10≤JIF<20，20≤JIF≤500。
可复制为自定义目录，按部分名称或 ISSN 搜索，按 JIF 范围筛选，或只显示已选期刊。
列宽可拖动，支持名称与 JIF 排序。多个目录可打包成 ZIP，供其它用户读取。
导入同名目录追加“_已重复”，不会覆盖原目录。
设置中的 JIF 年份默认本地电脑年份减一，可选择 2010 年至当前年。
按已录入的对应年度显示 JIF，缺失值留空，切换年份不改变 IF 三组成员。
不在线补全 JIF，不调用 Clarivate Journals API。
NLM 公开目录收录不能代表所有期刊均为 SCI，JIF 以本地录入数据为准。

显示与本地数据
--------------
设置支持根据屏幕宽度自动调整字体和布局，也可手动整体缩放。
软件及其弹出窗口保持浅色界面。
“备份本地数据（ZIP）”导出整个数据目录，包含数据库和 paper。
“移动本地数据目录”迁移到专用空目录，验证后删除原数据，并继续使用新路径。
“链接本地数据目录”选择已有目录本身，其中应直接包含 biomed_literature.sqlite3。
目录结构不正确时提示并拒绝链接。迁移前请先备份。
路径选择窗口支持在 Look in 中输入或粘贴路径，按 Enter 进入。

关键词方案默认展现形式
--------------------
设置可选择宽松的嵌入式卡片、紧密的嵌入式卡片或表格，默认紧密的嵌入式卡片。
每次重新启动软件，每个关键词方案使用设置中的默认形式。
方案内修改展现形式与密度仅在本次运行有效，不改变全局默认值。
点击 DOI 后保持原有字体淡化效果，卡片背景始终为白色。


2.1 新增功能
关键词方案右上角“全部联网刷新”按当前卡片顺序依次检索；首次建立完整基线，以后沿用各来源成功日期做按日增量检索。可取消整个队列，保留已经保存的新结果。部分方案失败时继续处理其余方案，最后汇总错误。
文章详情“导出 / 复制引用”依据设置所选期刊生成文本引用，默认 Cell。NC扩选专属 CSL 样式可用时使用该样式，否则明确标注出版社通用或 NLM 通用后备样式。缓存缺失卷、期、页码或结构化作者时，需要自行核对补全；生成结果不是元数据完整性担保。

Word 插件（Windows 桌面 Word 2021 及以上）
安装程序为当前用户注册名为“Biomed Reader”的 COM 加载项；安装后重新打开 Word。无需修改宏安全策略。不支持 Word 网页版和 WPS。
1. 打开 Biomed Reader，在收藏文章中选择文章（表格选中，或卡片勾选“选择”），保持软件运行。
2. 在 Word 光标处选择 Biomed Reader → 插入引用。来源分组和文章元数据随文档保存。
3. 选择期刊：下拉列表，或“选择期刊…”输入关键词查找。点击“更新引用文献”应用新样式并按正文顺序重新编号。
4. 更新时，如果文章不再存在于最初引用的收藏分组，会删除该条引文并重排编号。文章仅移到别组也视为从原分组删除。未分组视图选中文章时，优先绑定其已有分组；没有分组则绑定收藏状态。
5. “参考文献字体”统一设置标记与文末参考文献的字体及字号。
6. 插件只处理自身生成的域，不处理 EndNote/Zotero 等其它插件的域。

EndNote 接管
“导出为 EndNote”需要已安装并启用 EndNote 桌面版的 Word CWYW 插件，保存文档副本并保留原稿。
副本包含原生 EndNote EN.CITE 引文域、嵌入文献记录（包括卷页）及由 CWYW 生成的 EN.REFLIST 文末参考文献。
可由 EndNote 直接更新引用与参考文献，需要独立文献库时使用 Export Traveling Library；无需再转换 Word 原生 CITATION 域。

样式目录范围说明
Word 期刊列表采用 NC扩选与已核实 EndNote 样式名称的交集，使用 NLM 标准期刊名/缩写精确对应。当前已核实的 Word 期刊列表为 39 本。本次核实基于本机安装的 EndNote 20 样式；官方完整目录访问返回 403，因此当前列表不声称穷尽官网全部支持期刊。未打包 EndNote 专有 ENS 文件。
EndNote 软件及许可证不包含在此安装程序中。企业策略可能限制 COM 加载项；本软件不会降低 Office 安全设置。

搜索已收藏文章
--------------
在“收藏文章”点击“搜索已收藏文章…”，选择一个或多个分组，输入关键词后搜索。
多个词用空格分开时需全部匹配，可用英文双引号包围完整短语；不使用 AND/OR 表达式。
仅在所选分组的本地标题、摘要、作者、期刊、DOI、标签和笔记中搜索，不读取 PDF 全文，不联网。
分组展示时只保留有匹配文章的分组，组内也仅展示匹配文章；不分组展示时合并去重后显示匹配文章。
表格、卡片和排序设置继续生效。点击“清除搜索”恢复全部收藏，筛选不会删除或修改文献库。

批量取消收藏
------------
点击“批量取消收藏…”，像打包分享一样选择分组和右侧文章；分组确定候选范围，最终按右侧所有已勾选项处理。
包括因窗口内搜索暂时隐藏的已勾选项，请在最后确认窗口核对篇数。
点击“批量取消收藏”后还会弹出确认窗口，说明全部分组移除和 PDF 副本删除；默认选项为保留收藏。
确认后逐篇处理。PDF 被占用时该篇的收藏、分组和链接保留，其它成功项正常取消；报告中可展开查看失败详情。

软件更新
--------
“设置 → 软件更新 → 检查软件更新”读取官网公开的版本清单，不需要 GitHub 账号或 GitHub CLI。
相同版本（例如本机与官网都为 2.1）提示已是最新；本机版本更高时不降级。
发现新版本时自动选择适合 Windows 或 macOS 芯片的 GitHub 安装包，再选择保存位置。下载时校验大小和 SHA256，失败或取消不会覆盖原有文件。
下载完成后请关闭 Biomed Reader 和 Word，再自行运行安装包；软件不自动启动安装程序。
更新项下方的官网链接使用默认浏览器打开：https://amiba-xqq.github.io/Biomedreader/
